# 🌿 EcoTrack AI

An AI-powered app that calculates your carbon footprint and rewards you for living sustainably.

---

## ⚡ Quick Start

```bash
# 1. Clone the repo
git clone [https://github.com/your-username/ecotrack-ai.git](https://github.com/your-username/ecotrack-ai.git)

# 2. Go to project directory
cd ecotrack-ai

# 3. Install dependencies
npm install

# 4. Start the app
npm run dev
